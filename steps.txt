Epic 2: AI 추론 서버 구축 (FastAPI)
------------------------------------------------------------

[ ] Feature 2-1. KcBERT 모델 Fine-Tuning (3단계 감성 분류)
  - 학습 데이터: 커피 리뷰 텍스트 + Positive/Neutral/Negative 레이블
  - menu_relevance 분류기 포함
  - 악성 프롬프트 패턴 학습 데이터 포함 (Prompt Injection 방어)
  - 목표: Classification Accuracy 90% 이상, False Positive Rate 5% 미만

[ ] Feature 2-2. KcBERT 모델 ONNX 양자화 및 FastAPI 서버 세팅
  - 파인튜닝 모델 → ONNX 변환 + INT8 양자화
  - AVX2 최적화 ONNX Runtime 적용
  - ai-server/models/ 에 .onnx 파일 배치
  - Gunicorn(멀티 워커) + Uvicorn 서버 설정
  - Cold Start < 2s 목표

[ ] Feature 2-3. /api/v1/analyze-review 엔드포인트 구현
  - Request: { user_id, cafe_id, menu_id, review_text }
  - 입력 정제: regex 특수문자 무해화, control token 제거, XSS escape, 500 토큰 제한
  - 3자 미만 입력: 400 Bad Request (클라이언트에서도 사전 차단)
  - ONNX 추론: sentiment(positive/neutral/negative) + confidence + menu_relevance
  - menu_relevance 낮음 → Neutral 처리
  - Response: { status, sentiment, confidence, menu_relevance, latency_ms }
  - P99 200ms 이하, Max TPS 500 목표
  - ai-server/app/api/, ai-server/app/models/, ai-server/app/core/

[ ] Feature 2-4. 보안 및 Abuse 대응
  - Rate Limiting (동일 카페 반복 리뷰 제한)
  - Spam Detection
  - 리뷰 Soft Delete 엔드포인트
  - 신고 처리 API

[ ] Feature 2-5. 관리자 API
  - 메뉴 추가/수정 (JWT 인증 + RLS)
  - 리뷰 Soft Delete
  - 신고 처리

[ ] Feature 2-6. 블루-그린 무중단 배포 설정
  - Docker 블루-그린 전환 스크립트
  - Nginx Reverse Proxy 설정
  - Linux cgroups CPU 할당
  - HPA: CPU 70% 초과 시 수평 확장

[ ] Feature 2-7. 모니터링 설정
  - Prometheus: API latency, inference latency, cache hit ratio, DB query latency, error rate 수집
  - Grafana 대시보드 구성
