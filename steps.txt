[진행중] Feature 2-1. KcBERT 모델 Fine-Tuning (3단계 감성 분류)
  - [완료] 학습/검증 데이터셋 구성 (ai-server/models/train_dataset/, valid_dataset/)
           커피/디저트/음료/직원/인테리어/식당/TMI 리뷰 CSV 7종 + coffee_professional_reviews2.csv
  - [완료] ModelTrain 클래스 구현 (ai-server/models/train.py)
           Full Fine-Tuning / LoRA 선택, AdamW 옵티마이저, F1 Score 검증
  - [완료] 3단계 감성 분류 이중 모델 구조 구현
           KcBERT (kcbert_onnx) → menu_relevance 이진 분류기 (KcbertRelevancePredictor)
           KoELECTRA (koelectra_onnx) → sentiment 이진 분류기 (KoelectraSentimentPredictor)
           confidence < 0.6 또는 menu_relevance < 0.5 → neutral 강제 → 3단계 감성 실현
           (ai-server/app/models/predict.py)
  - [ ] 악성 프롬프트 패턴 학습 데이터 포함 (Prompt Injection 방어)
  - 목표: Classification Accuracy 90% 이상, False Positive Rate 5% 미만

  - [완료] 파인튜닝 모델 → ONNX 변환 + INT8 양자화 스크립트
           (ai-server/app/models/onnx_kcbert.py, KAN-3 커밋)
  - [완료] ai-server/app/models/kcbert_onnx/ 에 .onnx 파일 배치
           (model.onnx, model_quantized.onnx, tokenizer 파일 일체)
  - [완료] Dockerfile 작성 (dev: uvicorn --reload / runner: gunicorn 멀티워커)
  - [완료] ai-server/main.py 추론 라우터 등록
           analyze_review, reviews, reports 라우터 포함, /health + /metrics 엔드포인트 구현
  - [완료] Gunicorn(멀티 워커) + Uvicorn 서버 설정
           Dockerfile runner 스테이지: gunicorn + UvicornWorker --workers 3
           PROMETHEUS_MULTIPROC_DIR 환경변수로 멀티프로세스 메트릭 집계 설정
  - [ ] AVX2 최적화 ONNX Runtime 적용 (현재 onnxruntime==1.18.0 기본 패키지 사용 중)
