Epic 1: 백엔드 및 인프라 구축 (Supabase)
------------------------------------------------------------

[완료] Feature 1-1. Supabase DB 스키마 설계 및 인덱스 설정
  - cafes 테이블에서 menu_tags TEXT[] 제거 (menus 별도 테이블로 분리됨)
  - reviews 테이블에 menu_id FK, sentiment VARCHAR(20), menu_relevance FLOAT 컬럼 추가
  - menus 테이블 신규 생성 (id UUID PK, cafe_id FK, menu_name VARCHAR(100), created_at)
  - menu_scores 테이블 신규 생성 (id, cafe_id, menu_id, positive_count, neutral_count,
                                   negative_count, weighted_score, bayesian_score, updated_at)
  - GIST 인덱스: cafes.location (ST_DWithin 반경 검색)
  - btree 인덱스: reviews.cafe_id, reviews.user_id, reviews.created_at DESC
  - btree 인덱스: (menu_id, bayesian_score DESC) on menu_scores

[완료] Feature 1-2. RLS(Row Level Security) 정책 설정
  - cafes: anon/authenticated 전체 READ 허용, 쓰기 차단 (변경 없음)
  - reviews: anon INSERT → authenticated INSERT (auth.uid() 기준)로 정책 변경
  - menu_scores: authenticated READ 허용

[완료] Feature 1-3. Supabase 클라이언트 초기화
  - @supabase/supabase-js 패키지 설치
  - frontend/src/lib/supabase.ts 싱글톤 클라이언트 생성

[완료] Feature 1-4. 반경 내 카페 목록 조회 함수
  - ST_DWithin으로 현재 지도 화면 반경 내 카페 fetch (변경 없음)
  - frontend/src/lib/types.ts: Cafe 타입에서 menu_tags 제거
  - frontend/src/hooks/useCafes.ts: 반환 구조 확인 및 타입 동기화
  - supabase/migrations/20260507000001_create_get_cafes_within_radius.sql (RPC 함수)

[완료] Feature 1-5. 리뷰 저장 함수

  - reviews INSERT 시 sentiment, menu_relevance 컬럼 포함
  - frontend/src/lib/types.ts: AIAnalyzeResponse 타입을
    { status, sentiment, confidence, menu_relevance, latency_ms } 로 업데이트

[완료] Feature 1-7. 개발용 시드 데이터
  - cafes 시드: menu_tags 제거 (단국대 죽전 캠퍼스 반경 1km 내 카페 12개 유지)
  - menus 시드 신규 추가: 각 카페별 메뉴 전부 등록
  - 출처: 소상공인시장진흥공단 상가(상권)정보 경기 202603
  - supabase/seed.sql

[완료] Feature 1-8. Background Aggregation Worker
  - reviews INSERT 후 menu_scores 자동 집계 (PostgreSQL AFTER INSERT Trigger 방식 채택)
  - update_menu_scores_on_review() 함수: 전체 재계산(COUNT FILTER) 방식
    weighted_score = (pos*1.0 + neu*0.5 + neg*0.0) / total
    bayesian_score = (C*m + n*weighted) / (C+n), C=5, m=0.6
  - 시그니처 메뉴 조건 (함수 내 상수로 정의, 쉽게 변경 가능):
    MINIMUM_REVIEW_COUNT=5, BAYESIAN_THRESHOLD=0.7, POSITIVE_RATIO=0.6
  - menu_scores 테이블에 is_signature BOOLEAN 컬럼 추가
  - 엣지 케이스 처리: menu_id NULL → 즉시 종료, sentiment NULL → 카운트 제외,
    total=0 → 점수 NULL 유지 UPSERT, 첫 리뷰 → ON CONFLICT UPSERT로 신규 행 생성
  - supabase/migrations/20260522000001_feature_1_8_menu_scores_trigger.sql

[완료] Feature 1-9. GitHub Actions CI 파이프라인
