Epic 1: 백엔드 및 인프라 구축 (Supabase)
------------------------------------------------------------

[완료] Feature 1-1. Supabase DB 스키마 설계 및 인덱스 설정
  - cafes 테이블 (UUID, name, address, location GEOGRAPHY, menu_tags TEXT[])
  - reviews 테이블 (UUID, cafe_id FK, user_id, review_text, confidence_score)
  - GIST 인덱스: cafes.location (ST_DWithin 반경 검색)
  - GIN 인덱스: cafes.menu_tags (태그 교집합/합집합 검색)
  - btree 인덱스: reviews.cafe_id, reviews.user_id, reviews.created_at DESC

[완료] Feature 1-2. RLS(Row Level Security) 정책 설정
  - cafes: anon/authenticated 전체 READ 허용, 쓰기 차단
  - reviews: anon INSERT 허용 (confidence_score CHECK로 이중 보호)

[완료] Feature 1-3. Supabase 클라이언트 초기화
  - @supabase/supabase-js 패키지 설치
  - frontend/src/lib/supabase.ts 싱글톤 클라이언트 생성
  - NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY 연결

[완료] Feature 1-4. 반경 내 카페 목록 조회 함수
  - ST_DWithin으로 현재 지도 화면 반경 내 카페 fetch
  - 응답 데이터 메모리 캐싱 (동일 세션 캐시 적중률 80% 목표)
  - frontend/src/hooks/useCafes.ts
  - supabase/migrations/20260507000001_create_get_cafes_within_radius.sql (RPC 함수)
  - frontend/src/lib/types.ts (Cafe, MapCenter 타입)

[완료] Feature 1-5. 리뷰 저장 함수
  - AI 서버 승인(confidence >= 0.85) 후 reviews INSERT
  - 파라미터화된 쿼리 (SQL 인젝션 차단)
  - frontend/src/hooks/useSubmitReview.ts
  - frontend/src/lib/types.ts에 AIAnalyzeResponse 타입 추가

Epic 2: AI 추론 서버 구축 (FastAPI)
------------------------------------------------------------

[ ] Feature 2-1. KcBERT 모델 Full Fine-Tuning
  - 커피 리뷰 / 비커피 텍스트 이진 분류 데이터셋 구성
  - KcBERT 파인튜닝 (목표 F1 Score 0.90 이상)
  - 악성 프롬프트 패턴 학습 데이터 포함

[ ] Feature 2-2. KcBERT 모델 ONNX 양자화 및 FastAPI 서버 세팅
  - 파인튜닝 모델 → ONNX 변환 + INT8 양자화
  - AVX2 최적화 ONNX Runtime 적용
  - ai-server/models/ 에 .onnx 파일 배치
  - Gunicorn(멀티 워커) + Uvicorn 서버 설정

[ ] Feature 2-3. /api/v1/analyze-review 엔드포인트 구현
  - 입력 정제: 정규표현식 특수문자 무해화, 500 토큰 제한, 3자 미만 차단
  - ONNX 추론: P(y=1|x) = σ(W · h_[CLS] + b)
  - confidence >= 0.85 → 200 OK / 미만 → 406 Not Acceptable
  - P99 200ms 이하, Max TPS 500 목표
  - ai-server/app/api/, ai-server/app/models/, ai-server/app/core/

[ ] Feature 2-4. 블루-그린 무중단 배포 설정
  - Docker 블루-그린 전환 스크립트
  - Linux cgroups CPU 할당
  - HPA: CPU 70% 초과 시 수평 확장
